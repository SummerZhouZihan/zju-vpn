# zju-vpn

面向浙江大学用户的 Windows 网络分流与启动工具。结合 Clash 和 [zju-connect](https://github.com/Mythologyli/zju-connect)，在校内优先直连校园资源，在校外通过学校 VPN 访问校园资源，同时使用已有外网代理访问 Google 等网站。

## 项目解决什么问题

日常学习和科研中，校园内网与外网代理往往需要同时使用。例如，访问 CC98、校内系统或服务器的同时，还需要使用 Google 等服务。在校园网络与家庭网络之间切换时，这两类访问需求仍然存在，但校园资源的连接方式会发生变化。

zju-vpn 的目标是让应用使用同一个代理入口，由 Clash 根据访问目标和校园资源的可达性选择连接通道：

| 使用场景 | 校园资源 | Google 等需要代理的网站 |
| --- | --- | --- |
| 校内网络，资源可直接访问 | 优先使用本机网络直连 | 使用已有 Clash 外网代理节点 |
| 校外网络，资源无法直接访问 | 通过 zju-connect 连接学校 VPN | 使用已有 Clash 外网代理节点 |
| 重新回到可直连的校园网络 | 检测恢复后重新优先直连 | 继续使用已有 Clash 外网代理节点 |

其他网站沿用原有 Clash 分流规则。使用者需要自行准备可用的外网代理节点，以及具有相应访问权限的浙大账号。

## 工作原理

```text
应用 → Clash
         ├─ 校园资源 → 优先直连，检测不可用时选择 zju-connect → 学校 VPN
         ├─ Google 等 → 已有外网代理节点
         └─ 其他网站 → 原有分流规则
```

Clash 负责判断请求应走哪个出口，zju-connect 负责建立学校 VPN 连接。本项目将两者的配置和启动过程整合起来，添加校园分流规则、维护自动切换策略，并提供日常启动入口。

这里的学校 VPN 与用于访问 Google 的外网代理是两条不同的通道，分别服务于校园资源和外网访问。

## 适用范围

当前启动器适配 **Windows 与 Clash for Windows**，通过 zju-connect 的 aTrust 协议接入浙大 VPN。其他 Clash/Mihomo 客户端需要继续开发。

校园资源能否访问，仍取决于当前网络、学校 VPN 授权和资源本身的权限。连接学校 VPN 不代表自动获得所有实验室服务器或数据库的访问资格。

## 快速开始

1. **准备 Clash。** 安装 Clash for Windows，配置自己的外网代理节点，选择 **Rule** 模式并开启系统代理，确认 Google 等所需网站能够正常访问。
2. **打开启动窗口。** 双击 `start.cmd`，选择是否连接学校 VPN。在校内可以选择直连，不需要启动 zju-connect。
3. **按需准备学校 VPN。** 如果尚未安装 zju-connect，窗口会提供下载按钮；也可以跳过下载，先使用直连。下载完成后，选择连接学校 VPN，在同一窗口填写浙大账号和密码，按学校要求完成浏览器验证或提交短信码，无需再打开其他命令文件。
4. **完成后关闭窗口。** 操作结束后，可点击 **Close** 或按回车关闭窗口。已经连接的学校 VPN 会继续在后台运行。

窗口默认使用简体中文，可通过右上角 **Language** 即时切换为英文。

启动器会向当前 Clash 配置添加校园分流规则，必要时重启 Clash；外网节点和其他流量的处理继续沿用已有配置。配置修改前会保存备份。

校园流量优先直连；当直连不可用且学校 VPN 已连接时，自动选择 VPN。网络切换后的检测需要一定时间。未连接学校 VPN 是正常状态，校外需要访问校园资源时，可以再次打开启动窗口并选择连接。

## 账号与本机数据

本机配置、加密凭据、登录会话和日志保存在 `%LOCALAPPDATA%\zju-vpn`，与项目源码分开。账户密码加密保存，换机器或用户后需要重新登录。

登录会话、日志及 Clash 订阅配置可能包含敏感信息，请勿提交到 Git 或上传到公开问题中。完整说明见 [安全说明](docs/SECURITY.md)。
